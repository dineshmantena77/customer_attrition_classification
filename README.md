# Customer Attrition Analysis & Classification

A binary classification pipeline designed to predict customer churn probability based on historical service indicators such as tenure, monthly charges, and support calls.

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, Scikit-learn, Matplotlib

## Key Workflow Steps
1. **Exploratory Data Analysis (EDA):** Evaluated feature correlations to isolate primary factors influencing customer retention.
2. **Preprocessing:** Standardized input features and created an 80/20 train-test split.
3. **Classification Modeling:** Trained a baseline Logistic Regression classifier.
4. **Performance Benchmarks:** Evaluated test predictions using Accuracy, Precision, and Recall metrics.
